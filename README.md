# Natthachai Jansri - CV

Personal CV website built with Next.js (App Router) and TypeScript.

- Content lives in `lib/cv-content.ts` (Thai and English)
- Page UI lives in `components/CvPage.tsx`, styles in `app/globals.css`
- Profile photo lives in `public/images/profile.png`

## Development

```bash
npm install
npm run dev
```
